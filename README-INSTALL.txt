StudySpace Theme Studio add-on

Files:
- theme-studio.js: adds Theme Studio and five themes (Midnight Navy, Pink Y2K, Sage Garden, Dark Mode, Warm Minimal).

Install:
1. Upload theme-studio.js to the same folder as index.html, styles.css, and app.js.
2. Open index.html in your repository editor.
3. Add this line after the existing app.js script line:
   <script src="theme-studio.js" defer></script>
4. Save and refresh the website.

This add-on keeps your existing app files and saved assignments in place. Theme choice is saved locally in the browser.
If the site is cached, refresh the page once or reopen it.
